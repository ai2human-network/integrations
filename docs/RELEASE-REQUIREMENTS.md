# Release Requirements

An integration reaches `preview` only when it has:

- a five-minute quickstart;
- `.env.example` with placeholders only;
- executable smoke test;
- task classification guidance;
- explicit funding semantics;
- idempotent creation;
- status and proof retrieval;
- CI on supported runtimes;
- one controlled end-to-end trace;
- security and support boundaries.

`stable` additionally requires versioned packages, compatibility policy, contract tests, and two independent production adopters.
